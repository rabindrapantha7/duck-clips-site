Duck Clips

Duck Clips is a personal tool that edits short gaming clips and uploads them to the owner's own TikTok account, only after the owner reviews and approves each video.

It is not a public service. It has one user, the owner, and it does not post to, read from, or message any other account. It is not affiliated with or endorsed by TikTok, Rockstar Games or any streamer.

It uses Login Kit to authorize the owner's account and the Content Posting API to upload approved videos.
